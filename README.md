# factory-test-macos

A small, deliberately clean SwiftUI macOS app that the [Security Software Factory](https://github.com/AakashDadhich/security-factory) runs against. It should pass every security stage.

- The Xcode project is generated by XcodeGen from `project.yml` and is not committed.
- One Swift Package dependency, `apple/swift-log`, pinned exactly in `project.yml` and `Package.resolved`.
- App Sandbox on (`Config/FactoryTestMacOS.entitlements`), hardened runtime on, and a privacy manifest (`Sources/PrivacyInfo.xcprivacy`) that declares no tracking and no collected data.
- The factory builds it ad-hoc signed on a `macos-15` runner and uploads the zipped `.app`.
